#### Company-Wise Coding Questions

Once you know where you are interviewing, these lists show the questions each company has asked before, so you can practise the patterns it leans on.

1. [Company-wise Coding Questions](https://github.com/ayaanp14/company-wise-coding-questions) – Questions from 60+ companies (TCS, Infosys, Wipro, Accenture, Amazon, Google, Microsoft and more) sorted by difficulty, with a "start with these 10" list for each company and the questions the most companies ask. Rebuilt every night.  
2. [Company wise LeetCode Questions](https://github.com/krishnadey30/LeetCode-Questions-CompanyWise) – LeetCode questions for each company, sorted by how often they were asked.
